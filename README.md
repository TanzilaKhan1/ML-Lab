# ML-Lab — Bus & Leguna Door-Hanging Safety Classifier

A complete computer-vision project for detecting whether passengers are
**hanging on the doors of buses and legunas** — a common and dangerous safety
violation on Dhaka roads. The pipeline goes end-to-end from data collection
and annotation to a deployable prediction UI with model-agnostic explanations.

> Full methodology, dataset stats, training details, and per-model evaluation
> live in **[REPORT.md](REPORT.md)**. Compact results tables are in
> **[RESULTS.md](RESULTS.md)**. This README is the navigation map.

## Pipeline at a glance

```

         │
         ▼

                      │

                      │

```

## Dataset

| | Count |
|---|---|
| Total labelled originals | **523** |
| Safe (not hanging) | 272 |
| Unsafe (hanging) | 251 |
| Class imbalance | 1.08:1 (safe:unsafe) |
| Train (after augmentation) | **2,730** |
| Validation | 79 (real originals) |
| Test (untouched holdout) | 79 (real originals) |

Split strategy: 4-way stratified by vehicle × class (bus-safe, bus-unsafe,
legua-safe, legua-unsafe), 70 / 15 / 15. Augmentation is applied to **train
only** — no data leakage.

## Models

Nine models are trained, evaluated, and served by the predictor:

| Model | Family | Weights |
|---|---|---|
| **Ensemble (best)** | Deep — ResNet50 + ConvNeXt-Tiny | `ensemble.json` |
| ResNet50 | Deep — PyTorch transfer | `resnet50.joblib` |
| ConvNeXt-Tiny | Deep — PyTorch transfer | `convnext_tiny.joblib` |
| EfficientNet-B0 | Deep — PyTorch transfer | `efficientnet_b0.joblib` |
| ResNet18 | Deep — PyTorch transfer | `resnet_model.joblib` |
| CNN | Deep — custom SmallCNN | `cnn_model.joblib` |
| SVM (RBF) | Classical — HOG features | `svm_model.joblib` |
| Logistic Regression | Classical — HOG features | `logistic_model.joblib` |
| Naive Bayes | Classical — HOG features | `naive_bayes_model.joblib` |

Classical models operate on a 1,764-dim HOG feature vector
(9 orientations, 16×16 cells/block, L2-Hys) via a
`StandardScaler → PCA → classifier` sklearn `Pipeline`.
Torch models consume the raw 512×512 RGB image.

## Key results (test set, n = 79)

Three operating points are supported; **high-recall is the deployed default**
because missing a hanging passenger is worse than a false alarm.

### Balanced operating point (max accuracy)

| Model | Test acc | Unsafe recall | ROC-AUC |
|---|---|---|---|
| **Ensemble (best)** | **86.1%** | **94.7%** | **0.970** |
| ResNet50 | 92.4% | 92.1% | 0.967 |
| ConvNeXt-Tiny | 83.5% | 94.7% | 0.972 |
| SVM (RBF) | 87.3% | 89.5% | 0.952 |
| Logistic Regression | 81.0% | 81.6% | 0.887 |
| Naive Bayes | 73.4% | 73.7% | 0.866 |
| Majority baseline | 52.0% | 0% | — |

Full tables (all 9 models × 3 operating points × 21 metrics) in
[RESULTS.md](RESULTS.md).

### High-recall operating point

| Model | Test acc | Unsafe recall |
|---|---|---|
| **Ensemble (best)** | 86.1% | **94.7%** |
| ResNet50 | 83.5% | 92.1% |
| ConvNeXt-Tiny | 88.6% | 94.7% |

With the near-balanced dataset the tuned thresholds sit close together, so the
Ensemble reaches 94.7% unsafe recall (misses 2 of 38 hangers) at 86% accuracy.

## Components

### `annotator/`
Custom Next.js annotation tool backed by Cloudflare R2. Supports
bounding-box labelling, soft-trash, YOLO/COCO export, and rotation. Used to
produce the labelled dataset.

### `pipeline.py` and `model/`
The research/training side. `pipeline.py` is the end-to-end classical script
with group-aware splits and learning curves; `model/train_*.py` cover
individual classifiers (classical and deep). See [REPORT.md](REPORT.md) for
full methodology and [RESULTS.md](RESULTS.md) for results tables.

### `paper_assets/`
Twelve publication-quality figures (white background, muted professional
palette) and formatted tables generated by `model/rt_paper_assets.py` and
`model/make_paper_assets.py`.

### `predictor/` — the prediction app ★
A Streamlit application that lets anyone upload an image and get a prediction
**plus a visual explanation** of why the model decided what it did:

- **Upload** an image (JPG, PNG, WEBP, BMP, TIFF, HEIC/HEIF — iPhone photos work)
- **Preprocess** identically to training (EXIF-orient → 512×512 crop)
- **Predict** using any of the nine saved model pipelines (selectable in the
  sidebar) — returns SAFE / UNSAFE with per-class probabilities at three
  configurable operating points
- **Explain with LIME** — segments the image into superpixels, perturbs them,
  and fits a local linear surrogate to surface the regions that pushed the
  model toward its decision. Rendered as an overlay, a continuous red/green
  heatmap, and a top-regions-only view.

Only the selected model is held in memory (`lru_cache(maxsize=1)`) to stay
within small cloud-host limits. Torch models (`resnet50.joblib`,
`convnext_tiny.joblib`) are tracked via **Git LFS**.

The app has its **own poetry environment** scoped under `predictor/.venv`:

```bash
cd predictor
python3 -m poetry install --no-root
python3 -m poetry run streamlit run app_streamlit.py
# → http://localhost:8501
```

Full documentation: [**predictor/README.md**](predictor/README.md).

## Labels

| Label | Class | Meaning |
|---|---|---|
| `0` | negative (safe) | Passengers are **NOT** hanging on the door |
| `1` | positive (UNSAFE) | Passengers **ARE** hanging on the door |

The primary metric is **recall on the unsafe class** — missing an unsafe
passenger is more dangerous than a false alarm.

## Environments

There are **two independent poetry environments** on purpose:

- **Repo-root** (`pyproject.toml`, `poetry.lock`) — research/training:
  numpy, scikit-learn, scikit-image, matplotlib, torch, torchvision, etc.
- **`predictor/`** (`predictor/pyproject.toml`, `predictor/poetry.lock`) —
  the deployable Streamlit + LIME UI plus everything needed to load the
  joblib / `.pt` pipelines, isolated so it can be deployed independently
  (e.g. Render / Streamlit Cloud) without dragging in the training stack.
