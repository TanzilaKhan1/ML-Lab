# Paper assets — Bus/Leguna Door-Hanging Safety Classifier

Auto-generated by `model/make_paper_assets.py`. All figures are 200-DPI PNG;
tables are provided as Markdown + CSV (and the headline table as a figure).

**Task:** binary image classification — is a passenger hanging on a bus/leguna
door (UNSAFE) or not (SAFE)? Labels are ground-truth from annotation boxes.
**Data:** 385 images (287 safe / 98 unsafe), stratified 70-15-15 split. Deep
models also evaluated by 5-fold CV on the 327 train+val images (more reliable
than the 58-image test). GPU: RTX 5090.

## Headline numbers

- **Best balanced model:** Ensemble (ResNet50+ConvNeXt, 320px, TTA) — **CV 91.7% accuracy, 80.7% unsafe-recall, AUC 0.929**.
- **Highest test accuracy:** CNN 91.4% (but lower recall).
- **Operating modes** (Ensemble, CV): balanced 92%/81% · high-recall 75%/95% · zero-miss 26%/**100%**.
- The recall/accuracy ceiling (AUC ≈ 0.93) is **data-limited** (98 unsafe images, a few tiny/distant hangers + label noise) — see `fig7` and the project `RESULTS.md`.
